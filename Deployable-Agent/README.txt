======================================================================
  IT Asset Monitoring Agent - คู่มือการติดตั้งบนเครื่อง Client / PC อื่น
======================================================================

1. การตั้งค่า Backend IP Server:
----------------------------------------------------------------------
เปิดไฟล์ appsettings.json และตรวจสอบบรรทัด:
"BaseApiUrl": "http://192.168.27.145:5000"

* หมายเหตุ: 192.168.27.145 คือ IP ของเครื่อง Server (เครื่องปัจจุบันที่มี Backend API)
หากเครื่องปลายทางอยู่วง LAN เดียวกัน สามารถชี้มาที่ IP นี้ได้ทันที

2. วิธีทดสอบรันดูผลลัพธ์ทันที (Console Mode):
----------------------------------------------------------------------
ดับเบิลคลิกไฟล์:
   Run-Console-Test.bat
จะเปิดหน้าต่างดำขึ้นมาแสดงการ Scan Hardware, Software, RAM, Monitor 
และส่งข้อมูลเข้า Backend Server ทันที

3. วิธีติดตั้งเป็น Background Windows Service (รันอัตโนมัติเมื่อเปิดเครื่อง):
----------------------------------------------------------------------
คลิกขวาที่ไฟล์:
   Install-Service.bat -> เลือก "Run as administrator" (เรียกใช้ในฐานะผู้ดูแลระบบ)
โปรแกรมจะสร้าง Service ชื่อ "ITAssetAgent" ทำงานเบื้องหลังแบบ Silent อัตโนมัติ

4. วิธีลบหรือถอนการติดตั้ง:
----------------------------------------------------------------------
คลิกขวาที่ไฟล์:
   Uninstall-Service.bat -> เลือก "Run as administrator"

5. ข้อมูลที่เครื่อง Client จะส่งกลับมา:
----------------------------------------------------------------------
- ข้อมูลจะถูกส่งผ่าน HTTP/HTTPS เข้ามาที่ Backend Server พอร์ต 5000
- เครื่องที่เพิ่งลง Agent ใหม่ จะไปปรากฏบนหน้าเว็บ IT Admin Portal ทันที:
  http://192.168.27.145:3000/assets โดยมีสถานะเป็น "Unregistered"
- IT Admin สามารถกดปุ่ม "ลงทะเบียน" เพื่อระบุ Asset Tag (เช่น IT-PC-69-002) 
  และผูกแผนก/ผู้ใช้งานได้ทันที
======================================================================
